# Ayu for Codex

Copy `themes/*.tmTheme` files to `~/.codex/themes/` and restart Codex before importing the matching `themes/*.import.txt` line in **Settings > Appearance**. Each variant uses IoskeleyMono Nerd Font Propo for UI and code.
